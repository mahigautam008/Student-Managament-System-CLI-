This is my first console project for student management. This project will help you to perform many operations on the student data.


Programming Language : JAVA


Features : 
1. Add new students
2. Search Students via their 
respective roll numbers
3. Delete student 
4. View all students 


Concepts used :
1. OOPS
2. Arraylists
3. Basics of java :  variables, loops, methods .
